# Security Policy

## Reporting Security Issues

Please do not post exploitable security issues, private keys, tokens, signing material, account cookies, or service credentials in public issues.

If a private reporting channel is available on the GitHub repository, use it. Otherwise, open a minimal public issue that describes the affected area without including secret values or exploit details, and ask for a private contact path.

## Sensitive Material

Do not commit:

- Keystores or signing keys
- Signing passwords or signing property files
- `local.properties`
- `google-services.json`
- API tokens, bearer tokens, cookies, OAuth secrets, or service-account files
- Raw logs that include account, device, path, or request data

## Supported Versions

Security fixes target the current public release line unless a maintainer states otherwise in a release note.
