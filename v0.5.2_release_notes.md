# OmniTune v0.5.2 - The Premium Architecture & UI Update 🚀

This is a massive milestone release that brings OmniTune to full feature parity with premium competitors while fortifying its core architecture.

## 🎨 Phase 3: UI/UX Overhaul
- **Metro Player Layout:** Completely redesigned Player Screen with edge-to-edge album art, bold typography, and AMOLED black optimizations.
- **Home Screen Widget:** Added a fully native Jetpack Glance widget so you can control playback right from your launcher.
- **Custom Animations:** Replaced generic spinning loaders with a pulsing `OmniTuneLoader` that matches your dynamic theme.
- **Accessibility:** Added TalkBack semantic properties and merged nodes for visually impaired users.

## 🎵 Phase 2: Premium Audio Features
- **Advanced Audio Effects:** Real-time Tempo and Pitch adjustment using ExoPlayer's `PlaybackParameters`.
- **Silence Skipping:** Automatically fast-forward through dead air in podcasts or un-cut songs.
- **System EQ Integration:** Natively links into your device's built-in Equalizer/Audio processing suites.

## 🛠 Phase 1, 4, & 5: Architecture & Stability
- **Client Rotator:** Created a resilient API rotation engine to bypass InnerTube 403 blocks.
- **Database Speed:** Added SQL indices across all Room entities (`song`, `album`, `artist`) making large library loads incredibly fast.
- **Battery Life:** Re-configured `MusicService` to properly utilize `C.WAKE_MODE_NETWORK`, preventing heavy CPU wakelocks.
- **CI/CD:** Fully automated GitHub Actions pipeline that auto-builds debug and release APKs.
- **Firebase Ready:** Pre-configured Crashlytics and Analytics plugins (just drop in your `google-services.json`).
