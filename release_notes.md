# OmniTune v0.6.11 Icon Update

## Brand & Identity

This release updates the OmniTune application icon to the newly selected design. The icon has been professionally tailored into adaptive and legacy launcher icon formats to ensure it looks beautiful and "well mannered" across all Android home screens.

## Fixes and Changes
- **Icon Assets Updated**: Generated high-fidelity square and circular launcher icons across all standard Android device pixel densities (MDPI, HDPI, XHDPI, XXHDPI, XXXHDPI).
- **Adaptive Foreground**: Mapped the new icon design into the ic_launcher_foreground resource so it shapes itself perfectly into modern Android adaptive icon masks (squircle, teardrop, rounded square, etc.).
- **Version Bump**: Bumped app version to 0.6.11 (code 25) so that the in-app updater correctly detects and installs the new APK.
