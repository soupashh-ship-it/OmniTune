# OmniTune 0.7.0 Premium Polish Roadmap

0.7.0 should start only after the 0.6.x stabilization checklist is closed on physical devices.

## Product Polish

- Player UI: improve artwork treatment, typography scale, queue access, repeat/shuffle state clarity, and loading/error states.
- MiniPlayer: refine progress, swipe affordance, hit targets, and metadata fallbacks.
- Search UI: improve result grouping, skeleton states, cached/offline states, and long-title handling.
- Library: make liked songs, downloads, artists, albums, playlists, history, and recently played feel consistent.
- Downloads: add clearer progress, retry, completed metadata/artwork, storage usage, and failure explanations.
- Settings: reorganize playback, downloads, account integrations, privacy, appearance, and diagnostics.

## Engineering Quality

- Performance profiling: Compose recomposition audit, search-scroll profiling, artwork cache sizing, and startup trace review.
- Accessibility: TalkBack labels, contrast pass, dynamic type, touch target audit, and keyboard/media-control behavior.
- Crash and diagnostics: user-exportable bug report bundle with app version, device info, recent logs, and playback state.
- Release automation: signed release workflow, checksum generation, artifact naming, and release-note generation.
- Legal and attribution: keep GPL notices, Velune attribution, and NOTICE/CREDITS coverage current.

## Release Assets

- App icon polish.
- Store/release screenshots from real device states.
- Short release demo clips for playback, queue, downloads, and offline mode.

## Exit Criteria

- 0.6.x playback, force-stop recovery, queue, downloads/offline, notification controls, lock-screen controls, and network-disabled errors are all PASS.
- No known P0/P1 playback or data-loss bugs remain open.
- Debug and signed release builds pass from clean checkout.
