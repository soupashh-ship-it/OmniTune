## Fixes Made During RC Verification

1. **DownloadItemRow SwipeToDismissBox removed** — Deprecated `confirmValueChange` API did not prevent visual dismissal when Cancel was tapped, causing the download to be lost. Reverted to the original delete button + AlertDialog approach. The confirmation dialog already provides adequate protection against accidental deletion.

2. **Fallback MediaItem missing `.setTag()`** — Non-database-backed downloads created a MediaItem without `.setTag()`, causing `MusicService.onMediaItemTransition()` to set `_currentMediaMetadata = null`. This suppressed MiniPlayer visibility (`showMiniPlayer = false`) when playing downloaded songs.

## Remaining Limitations
- Android 11+ App-specific storage: uninstall permanently deletes downloaded files.
- OEM notification/lock-screen behaviors vary; not tested on all devices.
- Lyrics smooth auto-scroll needs human visual verification.
- Artwork sharpness at 800x800 needs human visual confirmation.

## Final Verdict
**READY ONLY AFTER HUMAN VISUAL QA** (lyrics auto-scroll, artwork sharpness — 2 items need a human eye).
