## Media Notification Path

Status: PASS

- Media3 `DefaultMediaNotificationProvider` is still used.
- Provider is now explicitly bound to OmniTune's playback channel ID and stable notification ID.
- Playback notification channel is configured as low-importance, public on lock screen, no badge, no sound, and no vibration.
- Small notification icon changed to the app-owned album vector icon instead of launcher foreground art.
- Debug-only `MediaControls` logs report notification permission, channel importance, session presence, player state, title, mediaId, and queue count.
- On iQOO/Funtouch OS, `dumpsys media_session` showed OmniTune playing while `dumpsys notification` initially showed only channel settings, not an active OmniTune notification record.
- Added a guarded platform `Notification.MediaStyle` fallback using the same channel and notification ID. It posts only when playback has a current media item and no active OmniTune playback notification exists.
- After the fallback, `dumpsys notification --noredact` showed:
  - `NotificationRecord ... pkg=com.omnitune.app ... id=1`
  - `channel=music_player`
  - `category=transport`
  - `actions=3`
  - `android.app.Notification$MediaStyle`
  - `android.mediaSession`
  - `vis=PUBLIC`
