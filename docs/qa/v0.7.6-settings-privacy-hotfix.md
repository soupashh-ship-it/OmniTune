# v0.7.6 Settings Privacy Hotfix QA

- Restored UI honesty by disabling fake/dead settings (Pause search history, Pause listen history, Hide explicit content, Hide video results, Pause on device mute, Pure black mode, Disable blur effects, Grid item size, Lyrics animation, and scrobbling). Replaced with clear `SettingsInfoBlock`s.
- Added working privacy controls: "Clear search history" and "Clear listen history" in Content Settings.
- Added working "Clear cache" control in Storage Settings that clears stream cache, image cache, and temporary resolver cache, explicitly stating it does NOT delete completed downloads.
- Improved diagnostic log sanitization replacing naive line-drops with robust Regex redactions for URLs and sensitive tokens (`authorization`, `cookie`, `session`, `password`, `token`, etc). Checked via `DiagnosticReportExporterTest.kt`.
