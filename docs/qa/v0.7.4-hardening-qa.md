# v0.7.4 Hardening QA Report

Status: **Pass**

## Overview
This report documents the verification of Phase 1-6 fixes for the OmniTune v0.7.4 hardening release. All critical playback, downloads, lyrics, and artwork regressions have been addressed without violating baseline architectures.

## Verification Checklist

### 1. Launch & Search
- [x] Launch app smoothly.
- [x] Perform search and observe fast results without blocking.

### 2. Search-Result Queue
- [x] Tap a search result.
- [x] Queue is built dynamically with lazy resolution.
- [x] Tapped song correctly plays.
- [x] Next and Previous buttons function logically within search results.
- [x] Search queue shuffle works properly without duplicating tracks.

### 3. Playback & MiniPlayer
- [x] Tap MiniPlayer body: opens the full player flawlessly.
- [x] Tap MiniPlayer Play/Pause: toggles playback correctly. DOES NOT accidentally open the full player.
- [x] Tap MiniPlayer Next: skips to next track correctly. DOES NOT accidentally open the full player.
- [x] Full Player controls order: Shuffle | Previous | Play/Pause | Next | Repeat.
- [x] "Previous" and "Next" buttons correctly disable when no track is available (honest disabled states).

### 4. Shuffle & Repeat Correctness
- [x] Repeat Off -> Repeat All -> Repeat One -> Repeat Off cycle correctly works.
- [x] Enabling shuffle keeps the current song playing smoothly.
- [x] Disabling shuffle restores the sensible original order.
- [x] **Queue Screen** accurately reflects the shuffled timeline.

### 5. Play Next & Add to Queue
- [x] "Play Next" inserts items properly.
- [x] "Add to Queue" appends items properly.

### 6. Downloads UI & Reliability
- [x] Downloads UI indicates active progress smoothly (poll delay reduced to 300ms, animation smoothed).
- [x] Completed downloads play immediately offline without attempting network resolution.
- [x] Cross button removed; safe Swipe-to-Dismiss implemented for deletion.

### 7. Lyrics
- [x] Synced lyrics auto-scroll follows playback correctly.
- [x] Manual swipe/drag pauses auto-scroll.
- [x] Auto-scroll resumes after a 3-second grace period following a manual swipe.

### 8. Artwork Quality
- [x] Notification, Full Player, and Android Auto correctly receive 800x800 high-res thumbnails instead of blurry 120x120 thumbnails.
- [x] MiniPlayer appropriately downsamples the 800x800 image to maintain low memory usage without duplicate network requests.

### 9. System Integrations
- [x] Background playback functions appropriately.
- [x] Reopen app after backgrounding correctly restores.
- [x] Notification controls respond properly.

## Known Limitations
- Android 11+ scoped storage means downloaded files are isolated to the app package directory. Uninstalling the app will permanently delete offline downloads. They cannot be recovered upon reinstall.
- OEM Lock-screen behaviors vary heavily across Android manufacturers (Xiaomi, Samsung, Oppo). Some controls may behave inconsistently on non-AOSP devices.
